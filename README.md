# Glow Up Assistant

Build a cute aesthetic Android app called "GlowUp - غلو أب" in Flutter.

App Idea: All-in-one cute lifestyle assistant for girls.

Design Style: Very cute, pastel pink + beige + white, rounded corners, soft animations, kawaii icons, like Pinterest.

Features:

1. ONBOARDING: Cute girl avatar asks "What's your goal today?"

2. FOOD CALORIE TRACKER:

- User takes photo of food or types name "رز بالدجاج"

- App estimates calories automatically (use simple database)

- Show daily circle progress: 1200 / 1800 kcal with cute donut chart

3. DAILY ROUTINE:

- Morning / Afternoon / Evening checklist: water, skincare, study, sleep

- User ticks and gets stars and cute motivational quote "أحسنتي يا ملكة!"

4. WORKOUT LOG:

- Buttons: Walk, Yoga, Gym, Dance with cute icons

- User logs minutes, app calculates burned calories and shows cute character doing workout

5. OUTFIT COORDINATOR (Main feature):

- User takes photos of her clothes (tops, pants, hijabs, bags, shoes)

- App removes background and saves in virtual closet

- Button "نسقي لي لبس اليوم" - app randomly mixes and suggests 3 cute outfits

- User can save favorite outfits

6. MOTIVATION:

- Daily push notification at 8am with cute quote

- Streak counter with fire emoji

Tech: Flutter, local storage (Hive), no login needed, Arabic + English, very simple.

Make it ready to run and make the UI super cute and girly.
